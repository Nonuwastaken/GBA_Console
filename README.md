# GBA_Console
A custom retro gaming handheld built from scratch on a Pi Zero 2W (RetroPie): 3D-printed shell, SPI TFT display, MCP23017 buttons w/ volume &amp; turbo controls, I2S audio, Wi-Fi/Bluetooth, and a full battery system (BMS, Buck, ADC monitoring). Built from discrete parts, not a kit — hands-on embedded systems, power electronics &amp; Linux integration.
